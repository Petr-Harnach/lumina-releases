# Lumina System Manager

Moderní, lehký a bleskurychlý nástroj pro diagnostiku, správu a údržbu operačního systému **Windows** a **Linux**.

Lumina kombinuje výkon a nízkou spotřebu systémových prostředků nativního C++ jádra s moderním tmavým glassmorphic rozhraním postaveným na technologiích Microsoft WebView2 (Windows) a WebKitGTK (Linux).

---

## 🚀 Rychlé stažení & Instalace

### 🪟 Pro Windows
Nejnovější verzi moderního grafického instalátoru stáhnete přímo zde:
* **[Stáhnout LuminaSetup.exe (Poslední vydání v1.3.0)](https://github.com/Petr-Harnach/lumina-releases/releases/latest/download/LuminaSetup.exe)**

1. Stáhněte a spusťte `LuminaSetup.exe`.
2. Zvolte instalační složku a potvrďte instalaci.
3. Instalátor automaticky nakonfiguruje systémovou službu na pozadí a vytvoří zástupce na ploše i v nabídce Start.
